# Tools and Common Dependencies Layer

English | [中文](./README.zh-CN.md)

---

This layer contains reusable tools, visual-geometry support libraries, and map-format conversion utilities.

## Packages

- `vikit_common`: C++ visual geometry, camera models, image alignment, and optimization utilities.
- `vikit_ros`: ROS 2 bridge utilities for vikit.
- `vikit_py`: Python trajectory, math, and ROS helper utilities.
- `pcd2pgm`: Converts PCD point clouds into 2D occupancy grids usable by Nav2.

This layer provides shared libraries and offline/semi-offline tools rather than online control or main SLAM/navigation logic.
